| **Eliminar mis propiedades** |
| - |
| Como locador, quiero eliminar los datos de una propiedad, para dejar de ofrecerla en alquiler permanentemente. |
| **Criterios de aceptación:** |
| - Se debe haber iniciado sesión con el usuario locador dueño de la propiedad. |
| - La propiedad a eliminarse no debe encontrarse actualmente alquilada. |
| - Se debe solicitar confirmación para eliminar la propiedad. |
| **Pruebas de usuario:** |
| - Probar eliminar una propiedad y la misma deja de ser visible en la búsqueda de alquileres y la sección de "mis propiedades" del locador (pasa). |
| - Probar eliminar una propiedad sin ser el dueño de la misma (falla). |
| - Probar eliminar una propiedad que se encuentra alquilada (falla). |
| - Probar eliminar una propiedad que no se encuentra alquilada (pasa). |
