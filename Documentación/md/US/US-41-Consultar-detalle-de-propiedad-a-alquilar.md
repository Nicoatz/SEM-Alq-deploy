| **Consultar detalle de propiedad a alquilar** |
| - |
| Como locador o locatario quiero consultar el detalle de una propiedad publicada para conocer si sus datos coinciden con lo que busco alquilar. |
|**Criterios de aceptación:**|
| - Se deben mostrar las fotos asociadas a la propiedad, hasta un máximo de 5 a la vez y las demás detrás de un botón. |
| - Se debe mostrar la dirección, altura, número de piso (si corresponde) y barrio de la propiedad. |
| - Se debe mostrar el monto del alquiler. |
| - Se debe mostrar el monto de expensas. |
| - Se debe mostrar la fecha desde la que se encuentra disponible el inmueble si corresponde, o "ahora mismo" en caso de que no se haya especificado una fecha. |
| - Se deben mostrar todas las características de la propiedad: superficie cubierta en m², cantidad de baños, cantidad de ambientes. |
| - Se deben mostrar todos los tags de la propiedad: si posee balcón, acepta mascotas, cochera, es amoblado. |
| - Se deben mostrar los servicios que posee la propiedad (agua y luz se asume que sí, por lo que no se muestran): gas natural, internet. |
| - Se debe mostrar la descripción asociada a la propiedad. |
| - Se deben mostrar los detalles asociados al contrato de la propiedad: gastos a cargo del locatario, plazo del contrato, índice de actualización, depósito, si se debe presentar comprobantes. |
| - Se deben mostrar todos los medios de pago existentes en el sistema, resaltando los aceptados por el locador. |
| - Se debe mostrar de un botón para solicitar alquiler por medio de la plataforma. |
| - Se debe mostrar de un botón para enviar un mensaje por whatsapp al número asociado del locador. |
| - (El botón para enviar mensaje a través de la plataforma, la visualización de ubicación aproximada y propiedades similares quedan para otro sprint.) |
|**Pruebas de usuario:**|
|- |
|- Probar consultar el detalle de una propiedad y sus datos asociados se muestran correctamente (pasa). |
|- Probar consultar el detalle de una propiedad y ver más de 5 fotos al pulsar sobre el botón para ver más fotos (pasa). |
