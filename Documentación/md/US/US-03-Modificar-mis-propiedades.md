| **Modificar mis propiedades** |
| - |
| Como locador, quiero modificar los datos de una propiedad, para mantener su información actualizada. |
| **Criterios de aceptación:** |
| - Se debe haber iniciado sesión con el usuario locador dueño de la propiedad. |
| - La propiedad a modificar no debe encontrarse actualmente alquilada. |
| - Se deben precargar los datos existentes de la propiedad. |
| **Pruebas de usuario:** |
| - Probar modificar una propiedad y los nuevos datos se reflejan en la publicación (pasa). |
| - Probar acceder a la url para modificar una propiedad desde un usuario que no es dueño de la propiedad (falla). |
| - Probar modificar una propiedad que ya se encuentra alquilada (falla). |
| - Probar modificar una propiedad que no se encuentra alquilada (pasa). |
