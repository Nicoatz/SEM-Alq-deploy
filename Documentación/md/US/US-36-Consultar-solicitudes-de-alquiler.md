| **Consultar solicitudes de alquiler** |
| - |
| Como locador o locatario quiero consultar mis solicitudes de alquiler para conocer su estado e información. |
| **Criterios de aceptación:** |
| - Se debe haber iniciado sesión. |
| - Se debe visualizar el estado de la solicitud (aceptada, rechazada, en espera). |
| - Para el locador, se debe visualizar el nombre y apellido de quien envió la solicitud. |
| - Para el locatario, se debe visualizar la dirección de la propiedad para la que se envió la solicitud. |
| - Se debe visualizar la imagen principal de la propiedad asociada a la solicitud. |
| - Se debe leer el mensaje opcional incluido por el locatario, si lo hubiera. |
| **Pruebas de usuario:** |
| - Probar consultar solicitudes de alquiler y se observan todos los datos asociados a la misma (estado, imagen principal de la propiedad, nombre y apellido o dirección, mensaje opcional) (pasa). |
