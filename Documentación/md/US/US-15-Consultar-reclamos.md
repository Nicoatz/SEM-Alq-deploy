| **Consultar reclamos** |
| - |
| Como locador o locatario quiero consultar los reclamos asociados a mis propiedades para llevar un seguimiento de los mismos. |
| **Criterios de aceptación:** |
| - Se debe haber iniciado sesión como locador o locatario. |
| - Si no hay reclamos para ninguna propiedad de la que se sea locador o locatario, informarlo con un mensaje amigable. |
| - Al consultar todos los reclamos, se debe mostrar la propiedad del reclamo con su imagen principal y dirección, el estado del reclamo (abierto, en proceso, resuelto, cancelado), el tipo de reclamo y un fragmento del mensaje asociado al reclamo. |
| - Al consultar todos los reclamos, si se es locatario se debe mostrar la foto de perfil y nombre del locador; si se es locador se debe mostrar la foto de perfil y nombre del locatario. |
| - Al consultar el detalle de un reclamo, se deben observar todos los datos visibles al consultar todos los reclamos, pero se debe mostrar el mensaje asociado en su totalidad y las fotos asociadas. |
| **Pruebas de usuario:** |
| - Probar consultar reclamos sin haber reclamos existentes asociados al locador o locatario (pasa). |
| - Probar consultar reclamos y se muestran todos los datos asociados al reclamo. |
