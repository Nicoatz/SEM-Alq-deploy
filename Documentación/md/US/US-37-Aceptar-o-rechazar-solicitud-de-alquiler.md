| **Aceptar o rechazar solicitud de alquiler** |
| - |
| Como locador quiero aceptar o rechazar solicitudes de alquiler para avanzar con el contrato del locatario elegido. |
| **Criterios de aceptación:** |
| - Precondición: se debe ingresar a la sección para consultar solicitudes de alquiler. |
| - Se debe distinguir claramente el botón de aceptar y el de rechazar, haciendo uso de colores y/o iconografía adecuada. |
| - Se debe solicitar confirmación antes de aceptar o rechazar una solicitud. |
| - Se puede incluir un mensaje de hasta 200 caracteres para aclarar el motivo del rechazo de la solicitud. |
| **Pruebas de usuario:** |
| - Probar aceptar una solicitud de alquiler y verificar que la solicitud pase a estado aceptada (pasa). |
| - Probar rechazar una solicitud de alquiler y verificar que la solicitud pase a estado rechazada (pasa). |
| - Probar rechazar una solicitud sin incluir un mensaje (pasa). |
| - Probar rechazar una solicitud con un mensaje de más de 200 caracteres (falla). |
| - Probar rechazar una solicitud con un mensaje de menos de 200 caracteres (pasa). |
