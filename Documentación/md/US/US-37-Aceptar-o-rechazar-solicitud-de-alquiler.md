| **Aceptar o rechazar solicitud de alquiler** |
| - |
| Como locador quiero aceptar o rechazar solicitudes de alquiler para avanzar con el contrato del locatario elegido. |
| **Criterios de aceptación:** |
| - |
| - Se debe distinguir claramente el botón de aceptar y el de rechazar, haciendo uso de colores y/o iconografía adecuada. |
| - Se debe generar y enviar una notificación por mail al locatario que se le haya aceptado la solicitud. |
| **Pruebas de usuario:** |
| - Probar aceptar una solicitud de alquiler y se genera y envía una notificación por mail al locatario (pasa). |
